# Claude-2

IA locale, entraînable, sans dépendance cloud — via [Ollama](https://ollama.com)
et un fine-tuning LoRA maison.

👉 Guide complet : [`docs/GUIDE.md`](docs/GUIDE.md)

Démarrage rapide :

```bash
./ollama/setup.sh llama3.1:8b
ollama run llama3.1:8b
```

Pour entraîner ton propre modèle sur tes données, voir le dossier
[`training/`](training/) et le guide.
